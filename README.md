# Домашняя работа по ClickHouse

Работа выполнена на ClickHouse **25.8.33.6**. Исходный набор — **10 000 000 событий** из `listening_events.csv.gz` за 13–26 октября 2026 года. Все даты и часы в работе указаны в UTC.

## Где смотреть решение

В SQL-файлах находятся запросы в порядке выполнения. В отчётах рядом собраны результаты, ручные расчёты и ответы на вопросы. Нумерация разделов соответствует материалам задания.

| Раздел | Запросы | Результаты и объяснения |
|---|---|---|
| Подготовка стенда | [00_setup.sql](00_setup.sql) | [Проверка загрузки](results/Подготовка.md) |
| 1. Отчёт по странам | [01_report.sql](01_report.sql) | [Задание 1](results/Задание_1.md) |
| 2. Ключ сортировки | [02_order_by.sql](02_order_by.sql) | [Задание 2](results/Задание_2.md) |
| 3. Кодеки | [03_codecs.sql](03_codecs.sql) | [Задание 3](results/Задание_3.md) |
| 4. Материализованное представление | [04_mv.sql](04_mv.sql) | [Задание 4](results/Задание_4.md) |

Результаты запросов сохранены текстом из `/play`. Для измерений задания 2 использованы строки `Read` после обычных SELECT; объёмы и единицы оставлены в точности отображения клиента.

## Как запустить

1. Распаковать выданный архив стенда отдельно от решения. Положить `listening_events.csv.gz` в его папку `data`, рядом с `compose.yaml`. Сам gzip распаковывать не нужно.
2. В папке стенда выполнить:

   ```powershell
   docker compose up -d --wait
   ```

3. Открыть <http://localhost:8123/play>. Пользователь — `student`, пароль — `takt`.
4. На новом стенде выполнить `00_setup.sql`. Если исходная таблица уже загружена, достаточно проверок в конце этого файла: версия, 10 млн событий и диапазон дат.
5. Выполнить файлы `01_report.sql`–`04_mv.sql` по порядку. В `/play` каждая команда запускается отдельно, до завершающей точки с запятой.

В начале заданий 2–4 есть сброс и подготовка их учебных таблиц. Исходная `takt.listening_events` в этих заданиях используется только для чтения. Вставки истории и контрольных порций А и Б выполняются по одному разу; для повторного опыта нужно начать соответствующий файл с начала.

После работы в папке стенда выполнить:

```powershell
docker compose stop
```

Данные останутся в Docker-томе. Исходный gzip, сам стенд и файлы Docker-тома в комплект решения не включены.
